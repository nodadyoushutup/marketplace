# drawio

Author and repair clean `.drawio` diagrams (intentional lanes, readable padded
labels, dedicated edge corridors), plus Cursor custom-editor false-alarm triage.

## Contents

### Rules (Cursor)
- `drawio-layout.mdc` — layout, typography, and routing standards for `**/*.drawio`
- `drawio-editor.mdc` — editor open assertion ≠ broken XML

### Skills
- `drawio-author` — create or redesign diagrams under a layout contract
  - `references/style-recipes.md` — copy-paste `style=` strings (padding + contrast)
- `drawio-repair` — fix overlaps, stacked arrows, clipped / low-contrast labels

## Commands

- `drawio-author`
- `drawio-repair`
- `drawio-triage`
