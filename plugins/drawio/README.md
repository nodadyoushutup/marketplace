# drawio

Author and repair clean `.drawio` diagrams (intentional lanes, no overlapping
boxes, dedicated edge corridors), plus Cursor custom-editor false-alarm triage.

## Contents

### Rules (Cursor)
- `drawio-layout.mdc` — layout / routing standards for `**/*.drawio`
- `drawio-editor.mdc` — editor open assertion ≠ broken XML

### Skills
- `drawio-author` — create or redesign diagrams under a layout contract
- `drawio-repair` — fix overlaps and stacked arrows without changing meaning

## Commands

- `drawio-author`
- `drawio-repair`
- `drawio-triage`
