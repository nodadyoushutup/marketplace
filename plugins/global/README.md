# global

Core portable agent craft: standing posture, language style, coding workflow,
writing-for-agents, and the planning/debug/QA agent set.

Optional stacks live in sibling marketplace plugins (`agentmemory`, `docker`,
`terraform`, `browser`, `git`, `drawio`).

## Rules (Cursor)

| Rule | Purpose |
| --- | --- |
| `global-execute-first` | Do the work; scope-grill only when blocked |
| `global-change-intensity` | L0–L3 intensity tiers |
| `global-mcp-first` | Prefer ready MCP tools over CLI |
| `global-host-url` | Never give the user localhost URLs |
| `global-code-comments` | Sparse, durable comments only |
| `global-commit-messages` | Conventional Commits + PR titles |
| `global-policy-evolution` | Promote durable guidance into project policy |
| `global-python` | Python style, typing, Google docstrings |
| `global-javascript` | JS/JSX style, JSDoc, robustness |
| `global-html` | Semantic HTML, a11y, safety |
| `global-yaml` | YAML structure, quoting, secrets hygiene |
