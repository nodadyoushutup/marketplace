# global

Portable agent posture and writing craft. This plugin does not define
language standards, product planning, a tracker application, a git host,
or diagrams.

## Rules (Cursor)

| Rule | Purpose |
| --- | --- |
| `global-execute-first` | Do the work; scope-grill only when blocked |
| `global-mcp-first` | Prefer a ready connected tool over a side-path CLI |
| `global-host-url` | Never give the user a localhost URL |
| `global-failed-command` | Do not rerun a shell command that just failed |
| `global-pasted-secrets` | Do not copy a credential the user pasted |
| `global-bounded-tools` | In a long thread, answer the latest message with sliced output |
| `global-turn-budget` | Stop at 40 tool calls; skip topics the user ruled out |
| `global-policy-evolution` | Promote and sync repo-local multi-host project policy |
