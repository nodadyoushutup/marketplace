# ba

Product and planning craft: business analysis, executable plans, and external
research. Pair with **`global`** (posture / intensity) and **`code`**
(implementation).

## Agents (both)

| Agent | Purpose |
| --- | --- |
| `ba-business-analyst` | Shape problem, requirements, AC |
| `ba-planner` | Lock an executable plan for L3 work |
| `ba-researcher` | External evidence outside the repo |

## Commands

- `/ba` → `ba-business-analyst`
- `ba-plan` → `ba-planner` (+ `code-technical-lead` / `ba-researcher` as needed)
