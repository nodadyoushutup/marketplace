# Business analysis

1. Launch / follow `business-analyst` (read-only) with the user ask.
2. Deliver problem, outcome, requirements, acceptance criteria, out of scope, assumptions.
3. Hand off to `business-analyst-plan` / `business-analyst-planner` when architecture is still ambiguous, otherwise to implementation via `code-workflow` if the `code` plugin is installed.
